# Cafe Angel — React

Project React interaktif Cafe Angel dengan konsep café premium dark mode.

## Struktur

- `src/components/CafeDoor.jsx` — pintu dan interaksi buka pintu
- `src/components/CafeHeader.jsx` — header interior
- `src/components/CafeHero.jsx` — banner/menu hero
- `src/components/OrderForm.jsx` — form pemesanan dan daftar menu
- `src/components/Receipt.jsx` — nota pesanan
- `src/components/OrderSuccess.jsx` — pesan pesanan berhasil
- `src/pages/CafeExterior.jsx` — halaman depan café
- `src/pages/CafeInterior.jsx` — halaman setelah pintu dibuka
- `src/styles/door.css` — khusus desain pintu
- `src/styles/exterior.css` — halaman depan
- `src/styles/interior.css` — halaman dalam/header/hero
- `src/styles/order.css` — form dan menu
- `src/styles/receipt.css` — nota dan sukses
- `src/styles/responsive.css` — tampilan responsif

## Menjalankan

```bash
npm install
npm run dev
```
